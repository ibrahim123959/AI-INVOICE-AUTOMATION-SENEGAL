# 📚 Documentation

Ce dossier contient l’ensemble du savoir structuré de la plateforme AI Invoice Automation.
Il constitue la source de vérité unique sur le fonctionnement technique, métier, légal et opérationnel du système.

Cette documentation ne sert pas uniquement à expliquer le code.
Elle permet de rendre la plateforme :

auditée

traçable

maintenable

conforme

évolutive

C’est un actif stratégique du produit.

La plateforme traite des données financières, des documents comptables légaux et des décisions automatisées.
Elle doit donc être compréhensible, vérifiable et défendable face à :

des auditeurs,

des régulateurs,

des cabinets comptables,

et des partenaires institutionnels.


🎯 Objectif de cette documentation

Cette documentation permet à toute personne autorisée (développeur, expert comptable, auditeur, partenaire, investisseur) de comprendre :

comment une facture est traitée de bout en bout,

comment l’IA prend ses décisions,

comment l’humain intervient,

comment l’apprentissage se fait,

et comment la conformité réglementaire est garantie.

Elle est conçue pour répondre à la question clé :

“Peut-on faire confiance à ce système pour automatiser la comptabilité ?”


## 🧩 Organisation

La documentation est organisée en quatre dimensions complémentaires.

📁 technical/ — Vision ingénierie

Ce dossier décrit comment la plateforme est construite.

On y trouve :

la spécification des API (OpenAPI / Swagger)

les schémas de base de données

l’architecture du moteur OCR

le pipeline machine-learning

les métriques de performance

les procédures de déploiement et de rollback

Il permet à un ingénieur ou un DevOps de comprendre :

comment le système est déployé,

comment il communique,

comment il évolue,

et comment il est maintenu en production.


## 📁 business/ — Vision comptable & réglementaire

Ce dossier décrit comment la plateforme respecte la réalité comptable.

On y trouve :

le plan comptable SYSCOHADA

les règles d’imputation

les formats FEC et Sage

les exigences de traçabilité

les contraintes des cabinets et des auditeurs

Il garantit que l’IA ne fait pas “juste de la reconnaissance de texte”, mais travaille dans un cadre comptable légal.

C’est ici que l’on prouve que le système produit des écritures exploitables, vérifiables et conformes.


## 📁 user/ — Vision utilisateur

Ce dossier explique comment le produit est utilisé.

On y trouve :

comment démarrer

comment importer des factures

comment valider les résultats

comment corriger l’IA

comment exporter vers Sage ou le FEC

Il est destiné aux :

comptables,

responsables financiers,

équipes de validation.

  
## 📁 governance/ — Vision conformité & confiance

Ce dossier définit le cadre de confiance du système.

On y trouve :

la politique de protection des données

les mesures de sécurité

l’éthique de l’IA

le journal officiel des changements

C’est ce qui rend la plateforme acceptable pour :

des institutions publiques,

des grandes entreprises,

des audits légaux,

et des partenaires financiers.
